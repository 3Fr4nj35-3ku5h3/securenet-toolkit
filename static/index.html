Product

Assessment helpers for authorized environments

SecureNet Console wraps production-minded checks — TCP ports, TLS certificates, HTTP security headers, and DNS — behind a clear authorization gate. Built for analysts and engineers who need fast, explainable signals.

  • Port scan — common / limited ranges, optional banners
  • SSL/TLS — cert, expiry, version, advisory grade
  • HTTP headers — scored security header posture
  • DNS — core records + light subdomain resolution

Public console policy

Private IPs, localhost, and cloud metadata hosts are blocked. Port scans are capped. Rate limits apply. You must confirm authorization before every run.

CLI modules remain available in the repo for lab / owned networks under the same legal rules.
